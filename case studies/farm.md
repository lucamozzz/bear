Description: The collaboration involves three participants: a Farmer, a Farm and a warehouse man. 
The farm initiates the collaboration by sending the farmer information about the tomatoes that need to be harvested, including the exact location within the field. The farmer then moves to the specified area, harvests the tomatoes, and transports them to the warehouse. Upon arrival, the farmer notifies the warehouse manager about the incoming delivery. The warehouse manager then checks the current storage availability. If there is free space in the warehouse, the manager updates the farm with the exact shelf or storage location where the tomatoes have been placed. 
If there is no available space, the warehouse manager informs the farm. In response, the farm searches for an alternative nearby warehouse with available capacity and sends the new warehouse details to the warehouse manager for the tomatoes to be redirected accordingly.
